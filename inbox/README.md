# Inbox

Quick notes from anywhere: a phone, a share sheet, a synced folder. Drop
files here as they come; nothing here is memory yet. The session briefing
counts them, and `/ingest` moves each one into `senses/inbox/` with the date
it was swept (a new file landing, which `senses/` allows), then encodes it.

`brain door FOLDER` names one folder that syncs to this machine: what is
saved there from anywhere is moved in here at the start of the next session.
