# dormant/

Pages that faded: not linked, not recalled, not touched for six months. They
are out of the index and the graph but still on disk and searchable, and come
back by moving the file to `cortex/` and re-adding it to the index. A page
fades when nothing but the episodes it came from links to it; those episodes
keep their links, which `brain check` lists as links to dormant pages. Only
`/sleep` or `/maintain` move pages here, with the owner's approval and a log
line.
