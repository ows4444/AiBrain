# Express

Write $ARGUMENTS: an outline unless a draft, report or handoff is asked for. Name the gaps before writing. Save to `motor/`.

The research is already done, cited and connected. What is left is the
argument, and that part stays the owner's.

## Core rule

Every point traces to a page. Never introduce a number or quote with no page
behind it. Say plainly what the brain does not cover.

## Workflow

1. **Inventory:** which pages cover this, what is thin, what is missing. If
   coverage is under half the question, say so at the top. Report the gaps
   before writing, so the owner can encode more first.
2. **Surface disagreements.** They are where the owner has something to say.
3. **Build** in the mode asked:
   - outline: angle (what this argues that no single page does), points each
     tied to pages, weak points (one source, self-reported, `unverified`).
   - draft: only when asked, labelled a first pass to rewrite in their voice.
   - report: question / what the brain covers / where sources disagree / what
     could not be established / what would change this / pages read.
   - handoff: goal, state, decisions and why, open questions, where things live.
4. **Save** to `motor/` and offer to encode the finished piece back as an
   episode by the owner.
5. **Log** `DATE write <mode> <topic> -> motor/<file>` and
   `DATE recall write <topic> -> [[page]], ...` for the pages the piece rests
   on. Pages used for writing are recalled pages; without the line they look
   unused and drift toward `dormant/`.

## Calibration

If every point comes from one page, this is a summary of that page; say so.
A report whose claims cannot be checked is worth less than a short one that can.
