# Ebbinghaus, Memory (1885)

## What it is

A summary of [[hermann-ebbinghaus]]'s experiments on himself, learning lists
of nonsense syllables and testing how much remained after delays from twenty
minutes to a month.

## Claims

- This source says retention falls steeply in the first hour after learning
  and then levels off: the [[forgetting-curve]].
- It says relearning a list takes less time than learning it did; the time
  saved, which Ebbinghaus called savings, measures what was retained.
- It says repetitions spread over several days held a list longer than the
  same number of repetitions crammed into one day
  (supports:: [[spacing-effect]]).

## Candidates

- Savings - relearning is faster than first learning, and the difference measures memory
