# senses/

Put input here: clipped articles, transcripts, PDFs, exported chats, voice
notes, anything. `/ingest` encodes it into an episode in `cortex/episodes/`.

Nothing here is edited after it lands; the `protect_senses` hook enforces it.
If a file is wrong, add a corrected copy and re-encode, so the original stays a
faithful record of what arrived. `assets/` holds images and attachments.
